## Quick Start

New to the Gantt Chart Tool? Here's how to get started:

1. Install the application using the installer
2. Launch the application from your desktop or start menu
3. Enter your project name and start date
4. Add tasks using the "Add New Task" button
5. Use the chart to visualize and manage your project timeline
6. Export your project to your preferred format

## Key Features

### Task Management

Create and manage project tasks with customizable details including:
- Task name
- Start and end dates
- Price and funding information
- Responsible person/team

[Learn more about Task Management →](TASK_MANAGEMENT.md)

### Interactive Chart

The interactive Gantt chart allows you to:
- View task timelines visually
- Drag tasks to adjust dates
- Click for detailed tooltips
- Double-click for quick editing

[Learn more about Chart Interaction →](CHART_INTERACTION.md)

### Export Capabilities

Share your project in multiple formats:
- PDF for comprehensive documentation
- Excel for data analysis
- PowerPoint for presentations

[Learn more about Export Features →](EXPORT_FEATURES.md)
