# Task Management Guide

This guide covers how to effectively manage tasks in the Gantt Chart Tool.

## Creating Tasks

### Adding a New Task

1. Click the "Add New Task" button at the bottom of the interface
2. Fill in the task details in the dialog that appears:
   - **Task Name**: Enter a descriptive name for the task
   - **Start Date**: Select when the task begins
   - **End Date**: Select when the task completes
   - **Price**: Enter the budget allocated for this task
   - **Funding**: Enter any funding received for this task
   - **Responsible Person/Team**: Enter who is responsible for this task
3. Click "Save" to create the task
4. The task will appear in both the task list and the Gantt chart

### Task Properties Explained

- **Task Name**: Identify your task with a clear, concise name
- **Start/End Dates**: Define the timeline for your task
- **Duration**: Automatically calculated based on start and end dates
- **Price**: The estimated cost or budget for completing the task
- **Funding**: Any allocated money for the task
- **Responsible Person**: Individual or team assigned to the task

## Editing Tasks

### Method 1: Using the Task Dialog

1. Double-click on any task in either the task list or the Gantt chart
2. Modify any details in the dialog that appears
3. Click "Save" to apply your changes

### Method 2: Direct Chart Manipulation

1. **Move a Task**: Click and drag the middle portion of a task bar
2. **Change Start Date**: Drag the left handle of a task bar
3. **Change End Date**: Drag the right handle of a task bar
4. Confirm the change when prompted

## Organizing Tasks

Tasks appear in the order they are created, but they're visualized chronologically on the chart. Consider these tips for organizing your tasks effectively:

1. Create tasks in a logical order of execution
2. Group related tasks by using similar naming conventions
3. Schedule dependent tasks appropriately (tasks that depend on others should start after the preceding task)
4. Use consistent responsible persons/teams for related task groups

## Deleting Tasks

1. Double-click on the task you wish to delete
2. Click the "Delete" button in the dialog that appears
3. Confirm the deletion when prompted

## Best Practices

- **Task Names**: Use clear, action-oriented names
- **Timelines**: Be realistic about start and end dates
- **Responsible Persons**: Assign specific individuals rather than general teams when possible
- **Financial Tracking**: Keep price and funding information up to date
- **Task Granularity**: Break down large tasks into smaller, manageable subtasks

## Tips and Tricks

- Double-click tasks for quick editing
- Click tasks once for a detailed tooltip with key information
- Drag tasks on the chart for visual adjustments to timeline
- Hold Shift while dragging for finer control
- Tasks are automatically saved when you save the project
